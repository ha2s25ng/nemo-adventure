# v5.13.0 스테이지·월드 리뉴얼

30개 스테이지와 8개 지역을 유지하면서 지역의 모습, 적 편성, 클리어 목표와 수집 보상을 연결했다. 구매·해금·클리어 데이터는 초기화하지 않는다.

## 스테이지를 다시 할 이유

- 완주: 기존 순서대로 다음 스테이지를 해금한다. 첫 클리어는 기존 골드와 캡슐 교환권 1장.
- 신속 훈장: 보스 세 마리를 각각 광포화 전 75초 안에 격파. 후반 최적화 도전이며 진행 필수 조건이 아니다.
- 도전 훈장: 피격 제한, 한 번 이상 각성, 경험치 회수율 중 해당 스테이지의 목표를 달성한다.
- 새로운 추가 훈장마다 일회성 골드. 각 지역 마지막 스테이지는 일회성 300–1,000골드와 교환권 2장.
- 기존 클리어는 완주 훈장으로 옮긴다. 예전 클리어에 첫 클리어 교환권을 소급 지급하지 않는다. 기존 유저도 지역 마지막 스테이지를 다시 클리어하면 새 지역 보상을 받을 수 있다.
- 재도전은 기존 재도전 골드만 반복 지급한다. 이미 받은 훈장·교환권·지역 보상은 중복 지급하지 않는다.

교환권은 한 번 뽑기에 우선 사용한다. 10개 뽑기는 교환권 한 장을 90골드로 계산하고 부족한 만큼 골드로 지불한다. 뽑기 확률은 유지한다. 저장 실패 시 골드와 교환권, 획득품을 함께 되돌린다.

## 전투와 설명

스타 샷 기본 주기 0.68→0.85초, 삑삑이 공 1.12→1.40초, 리본 피해 계수 1.15→1.02. 다른 무기는 역할별 단일·다수 피해와 각성 유틸리티를 비교하고 불필요한 일괄 상향을 피했다. 세부 비교는 [밸런스 검토](balance-v5130.md)에 있다.

도감은 무기 15종의 실제 기본 행동·각성 행동·레벨별 변화에 맞췄다. 두 갈래 진화를 설명하던 도리 문구와 생존모드 연마 해금 알림을 제거했다. 단계별 각성 발견 조건은 유지한다.

초반 세 스테이지의 보스 출현 기준은 75·150·240초이며 이후 지역은 5–6분 구간으로 늘어난다. 이전 보스와 싸우는 중 다음 보스가 겹쳐 나오지는 않는다. 적의 무리·돌진·원거리·수호 편성을 지역별로 배치했다. 보스전 주변 잡몹과 후반 특수 몬스터 중첩 상한을 낮추고, 보스 진입·격파의 자동 회복 총량을 줄였다. 보스 공격과 적의 사전 준비 동작은 유지한다.

## 그래픽

니모·도리와 스킬 그림을 유지하고 새 지역 건물 8종, 나무 2종·연못, 기존 몬스터 6종을 같은 파스텔 외곽선 스타일로 제작했다. 몬스터는 256픽셀의 서로 다른 걷기 4프레임을 사용한다. 방향은 안정적인 3/4 시점의 좌우 반전이며 뒷모습을 새로 만든 것은 아니다.

30개 스테이지와 생존모드에 선명한 바닥색, 넓게 연결된 길과 중앙 전투 공간을 적용한다. 커다란 지역 건물을 나무처럼 반복하던 배치와 흐릿하게 늘인 바닥·화면 입자를 제거했다. 장애물 판정은 나무와 건물의 밑동을 기준으로 둔다. 실제 사용 신규 비트맵은 약 3.04MiB이며 지역 건물은 선택한 지역만 불러온다.

## 검증 범위

`node tests/logic/run.cjs`는 실제 엔진을 VM에서 실행한다. 보스 처치 시간 기록·마지막 보스의 훈장 반영·첫 클리어·재도전·기존 저장 이전·중복 지급 방지·실제 교환권 결제·저장 실패 원복, 모든 무기 설명과 새 몬스터 프레임 출력을 검증한다. 테스트 전용 페이지는 별도 저장·무한 골드·레벨업 버튼을 유지하고 온라인 랭킹에서 분리한다.

무기 피해 비교는 회피 손실을 배제한 통제 실험이다. 30스테이지를 사람이 전부 플레이해 클리어한 검증으로 해석하지 않는다.
