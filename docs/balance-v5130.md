# v5.13.0 무기 밸런스 검토

검토일: 2026-11-26. 통합된 실제 게임 엔진을 VM에서 실행했다. 이번 검토에서 추가 수치 변경은 하지 않았다.

## 판단

- 스타 샷 기본 주기 0.85초, 삑삑이 공 1.40초, 리본 계수 1.02를 유지한다. 도리의 단일 대상 우위는 유지되지만 초반부터 압도적인 차이는 아니다.
- 짧은 거리의 리본·소용돌이·종과 원거리 투사체를 같은 단일 대상 피해량으로 맞추지 않는다. 다수 공격, 감속, 탄환 제거의 보상이 다르다.
- 당장 추가 상향·하향할 근거가 확실한 무기는 찾지 못했다. 씨앗 덫의 각성은 적이 이동 경로를 따라오는 실전에서 별도 확인할 필요가 있다. 아래 고정 상대 배치에서는 이동 꽃길의 효율을 충분히 검증할 수 없다.
- 30스테이지 보스의 75초 신속 메달은 극후반 최적화 목표에 가깝다. 75초가 지나도 전투는 계속되므로 메달을 일반 진행의 필수 조건으로 사용하면 안 된다.

## 비교 조건

공격력 100, 영구 강화·코스튬·희귀 카드·광견병·축복 없음. 모든 치명타를 비활성화했다. 동일한 36초, 60Hz, 이동 경로와 적 배치를 사용했다. 각성은 7레벨에서 정상 획득한 뒤 지정 패시브 수치만 제거하여 각성 기믹 자체를 비교했다.

단일 상대는 반경 0.75이며 중심 간 거리가 약 2.25다. 다수 상대는 반경 0.43인 16마리다. 상대 체력은 고정해 사망·대체로 인한 변수를 없앴다. 따라서 다수 피해는 **16마리에게 가한 총 피해/초**이며 한 마리에게 주는 피해나 실전 처치 속도가 아니다. 적 AI, 탄막 회피 손실, 지형 장애물은 이 비교에 포함하지 않았다.

## 30스테이지 5칸 빌드 확인

실제 마지막 보스 반경 1.74를 적용했다. 보스 체력은 158,860이며 75초에 잡으려면 평균 2,118.1 피해/초가 필요하다. 비교 위치는 중심 간 거리 약 2.75(최소 2.5)로, 플레이어 반경 0.4와 보스 몸체가 겹치지 않는다.

영구 강화는 최대, 무기는 5개 모두 각성, 지정 패시브는 정확히 5개만 최대다. 실제 치명타를 활성화했다. 광견병·희귀 카드·축복은 없다. 전설의 멍법사 코스튬은 공격력 +12(총 142), 뽑기 선장 코스튬은 +20(총 150)이다.

공격 빌드: 기본 무기 / 구름 친구 / 리본 댄스 / 프리스비 / 바람 깃털. 패시브는 행운의 리본 / 용기의 목걸이 / 튼튼한 발톱 / 행운의 동전 / 질주의 리듬이다.

방어 빌드: 스타 샷 / 스타 오비트 / 달빛 종소리 / 솜사탕 소용돌이 / 프리스비와 각 지정 패시브다.
