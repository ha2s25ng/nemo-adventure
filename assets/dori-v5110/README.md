# 도리 캐릭터 에셋

- `portrait.webp`: 기존 니모와 같은 256×256 캔버스, 발 기준선 245px.
- `portrait-large.webp`: 512×512 큰 미리보기.
- `walk-8.png`: 96×96 프레임, 8열 × 5방향. 아래 / 오른쪽 아래 / 오른쪽 / 오른쪽 위 / 위. 왼쪽 방향은 반전해서 사용.
- `walk.png`: 기존 4프레임 렌더러에 맞춘 호환용 384×480 시트.
- `character.json`: 프레임과 방향 정보.
- `photos.js`: 도리 포토카드 89종. 원본 바이트 해시에서 만든 고정 ID를 사용.

실제 사진을 참고해 내장 image_gen으로 생성한 두 발 캐릭터. 보관함과 도리 카드 뒷면에 적용됨. 플레이 캐릭터 선택과 게임 제목 변경은 포함하지 않음.
